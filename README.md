# INNOVACUSH

El cushuro de nuestra tierra, transformado en innovación.

Web oficial de INNOVACUSH, emprendimiento de Cangallo, Ayacucho, que revalora el cushuro y lo transforma en productos innovadores: cupcakes, queques, yogurt, mermelada y chocotejas.

## Tecnología

- HTML5
- CSS3
- JavaScript Vanilla

Sin dependencias ni frameworks. 100% estático.

## Despliegue en GitHub Pages

Basta con subir el repositorio a GitHub y activar GitHub Pages (rama `main`, carpeta `/root`).
